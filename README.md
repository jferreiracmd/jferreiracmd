### Projects

**[Zenith Cube](../../../zenith-cube)** · reaction wheel attitude control
A cube that balances itself using the same principle that points a satellite. Discrete-MOSFET
H-bridge, Locked Anti-Phase drive, optical encoders designed into the flywheels, cascaded PID at
100 Hz over an IMU complementary filter. Schematic in KiCad, firmware in C on an STM32, Wi-Fi
telemetry on an ESP32-C3.

**[Structured Light System](../../../sls-underwater-lighting)** · INESC TEC internship
Real-time control of structured lighting for autonomous underwater vehicles. Sequencing algorithm
under seven simultaneous timing constraints, microsecond execution on a hardware timer, live
exposure adjustment by double buffering in RAM, React dashboard, and migration of the bridge layer
from Node.js to a native ROS node.
